# NeuroX---2-Channel-EOG-EMG-ESP32-Robot-Car
NeuroX: An advanced 2-channel Brain-Computer Interface (BCI) robotics system powered by an ESP32-S3 and dual BioAmp EXG sensors. It uses a custom, non-blocking DSP pipeline to translate real-time Electrooculography (EOG) eye movements into directional steering and Electromyography (EMG) signals into emergency stops.
